# MoneyPilot

Personal finance with an AI co-pilot: Plaid bank data in MongoDB, asked about in chat.

```bash
pnpm install
cp .env.example .env.local   # optional: runs in demo mode with nothing set
pnpm dev
```

Scripts: `dev`, `build`, `typecheck`, `lint`, `test`, `test:e2e`, `db:indexes`. Spec and status: `CLAUDE.md`.
